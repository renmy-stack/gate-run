# ふやせ！ゲートラン

スマホ広告でよく見る「数字ゲートで仲間を増やして走る」ゲームを、広告どおりに遊べる版。
左右にドラッグして ×3・+20 のゲートを選び、敵の群れ・ボス・ノコギリ・回るぼう・プレス・かべ・あなをよけ、灰色の人を仲間にしてゴールへ。最後は かいだん（人数を使って上り、段の倍率がかかる）。点数 = ゴール人数 × 倍率 を友達と競う（1回 約30秒）。

https://renmy-stack.github.io/gate-run/

## ファイル
- `sim.js` — コース（`COURSE`）と進行。決定的・DOM 非依存（Node でも動く）。数値を変えたら `SIM_VERSION` を上げる
- `game.js` — 描画（疑似 3D）・入力・結果・シェア（`#r=人数`）
- `bot.js` — テスト用ボット（ゲートは指定どおり、ほかの仕掛けは少し先まで試して いちばん減らない位置）
- `test_sim.js` — ゲートの選び方をぜんぶ試して、ぜんめつ率・最高・目先の大きいほうを取った場合を出す
- `trace.js LRLR...` — 選び方どおりに走ってアイテムごとの人数を出す
- `tools/icon.html` — アイコン（headless Chrome で 512×512 を撮る）

## 確認
`python -m http.server 8094` → `http://127.0.0.1:8094/`。`?shot=秒&tx=-1` でその時点まで早送りして止まる（`&in=_best.json` でボットの入力を流す。`node -e` で bot.js の inputs を書き出す）。コンソールで `ff(秒)`。
スクリプトを変えたら `game.js` の `VERSION`・`version.txt`・`index.html` の `?v=` を一緒に上げる。
